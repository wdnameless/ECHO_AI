# Requirements Manifest — trust-fixed one-button self-learning

Бриф дословно: «делай» + «я хочу нормальный модуль самообучения, чтобы ответы реально подстраиваились под юзера» + «И я хочу его просто включать кнопкой без костылей».
Решения Wave 0 зафиксированы через виджет (ниже — дословные выбранные опции).

| ID | Требование | Дословная цитата | Статус |
|----|-----------|------------------|--------|
| R01 | Нормальный модуль самообучения: ответы реально подстраиваются под юзера | «я хочу нормальный модуль самообучения, чтобы ответы реально подстраиваились под юзера» | in-spec |
| R02 | Включение одной кнопкой, без костылей | «И я хочу его просто включать кнопкой без костылей» | in-spec |
| R03 | Адаптация: стиль + факты | «Стиль + факты» | in-spec |
| R04 | Сигналы обучения: только 👍/👎 и правки | «Только 👍/👎 и правки» | in-spec |
| R05 | Кнопка = учиться и применять (ВЫКЛ: не пишет и не применяет) | «Учиться и применять» | in-spec |
| R06 | Исправление выученного: ручное редактирование правил/фактов | «Ручное редактирование» | in-spec |
| R07 | Применение везде: интервью, беседа, лайвкод, чаты | «Везде» | in-spec |
| R08 | Доказательство работы: набор эталонов | «Набор эталонов» | in-spec |
| R09i | Пустой профиль не приписывает ложные факты (Senior/TeamLead, confidence=1) | implicit из «нормальный» + «Стиль + факты» | in-spec |
| R10i | Один источник правды learned state: устранить дрейф SQLite/localStorage, сброс чистит оба | implicit из «нормальный модуль» | in-spec |
| R11i | Выключение не должно снимать жёсткое языковое правило RU/EN (сейчас внутри evolution block) | implicit из «Учиться и применять» + scope «Везде» | in-spec |

## Явно ВНЕ скоупа (не заказывали)
- Новые AI-провайдеры, векторная БД/эмбеддинги, облачная синхронизация.
- Автообучение на всей истории без оценок (отклонено: «Только 👍/👎 и правки»).
- Новые режимы/переключатели поведения помимо одной кнопки.
- Прочие пункты прошлой оценки (preflight аудио, CI gates) — отдельные задачи.
