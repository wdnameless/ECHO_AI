## ADDED Requirements

### Requirement: Поиск не блокирует первый токен

Веб-поиск MUST идти параллельно со сборкой промпта и коннектом LLM, а не
сериальным ожиданием до ~1100мс перед ними.

#### Scenario: Первый токен приходит без задержки поиска
- **Given** включён веб-поиск и свежий вопрос без кэша
- **When** запускается генерация ответа
- **Then** коннект к LLM стартует до завершения поиска; поздние результаты кэшируются на следующий ход

### Requirement: Точный детектор незавершённости

`looksUnfinished` MUST срабатывать только на явные признаки продолжения
(союзы, предлоги в конце, продолженческая пунктуация), а не на любые ≥3 слов
без точки.

#### Scenario: Вопрос без точки не ждёт лишние 630мс
- **Given** реплика «Какие хуки вы используете чаще всего» без терминальной пунктуации
- **When** срабатывает базовый gap-таймер 450мс
- **Then** вопрос уходит в ИИ без продления ×1.4

#### Scenario: Настоящее продолжение ждёт
- **Given** реплика «Мы используем эвент сорсинг в основном модуле,»
- **When** срабатывает базовый gap-таймер
- **Then** таймер продлевается, речь не режется

### Requirement: Параллельная сборка промпта

RAG-контексты, поиск по памяти, секрет и заголовки MUST запрашиваться одним
`Promise.all`; стиль читается синхронно из write-through кэша.

#### Scenario: Ход без сериальных задержек
- **Given** включённые RAG + память + cloud-эмбеддинги
- **When** собирается промпт
- **Then** общее время близко к максимуму из запросов, а не к их сумме

### Requirement: Тёплый ASR-канал

Base URL сайдкара MUST кэшироваться после первого успеха; WS-сессия MUST
переиспользоваться между репликами вместо teardown+re-probe.

#### Scenario: Новая реплика стартует без health-проверки
- **Given** сайдкар здоров и закэширован
- **When** начинается новая реплика
- **Then** стрим открывается без `/health`-задержки; при обрыве кэш сбрасывается

### Requirement: Ужатые VAD-полы

Фреймы MUST идти чаще (125мс), safety-таймер MUST быть 350мс, PCM MUST ехать
бинарным IPC вместо base64+atob.

#### Scenario: Обрыв final восстанавливается быстро
- **Given** сайдкар закрылся без final
- **When** срабатывает восстановление
- **Then** фолбэк стартует через ~350мс, а не 1200мс

### Requirement: Быстрый хендовер слотов

Сокеты MUST закрываться сразу по `final`; IDLE-мик MUST не захватывать слот.

#### Scenario: Стык реплик без линтер-задержки
- **Given** «them» получил final, «me» ждёт слот
- **When** приходит final-фрейм
- **Then** слот освобождается без 200/400мс таймеров
