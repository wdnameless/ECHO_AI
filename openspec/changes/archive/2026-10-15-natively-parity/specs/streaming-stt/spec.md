## ADDED Requirements

### Requirement: Облачный стриминговый STT

Один облачный WS-стриминг STT (первым — Deepgram) MUST транскрибировать речь
в реальном времени через единый интерфейс `StreamingSTTProvider`, за которым
могут последовать другие провайдеры без переделки шва.

#### Scenario: Стриминг приходит в ленту живым текстом
- **Given** выбран облачный стриминг-STТ и введён ключ
- **When** собеседник говорит
- **Then** частичные транскрипты появляются в ленте до конца реплики

#### Scenario: Локальный Nemotron остаётся дефолтом
- **Given** свежая установка без облачного ключа
- **When** идёт встреча
- **Then** транскрибация идёт через локальный пайплайн, облако не вызывается

### Requirement: Доверенный хост STT

Новый STT-эндпоинт MUST проходить trusted-hosts гейт: известный хост — молча,
неизвестный — только с явного подтверждения пользователя.

#### Scenario: Ключ не уходит на чужой домен молча
- **Given** кастомный стриминг-эндпоинт на неизвестном хосте
- **When** пользователь запускает стрим
- **Then** приложение показывает подтверждение с именем хоста до первого байта с ключом
