# Proposal: Natively parity — 7 слайсов clean-room

## Why
Сравнение 2026-10-12 (Pluely 1.2.34 vs Natively 2.9.2, ~2.9k★) зафиксировало разрывы:
RAG-память (у нас 91 строка подстановки vs их векторная память встреч), стриминговый
облачный STT (у нас REST, у них WS), глубина стелса, 9 персон, DOCX, Visual Answers,
экспорт истории, дистрибуция (у нас только Windows из CI). Пользователь: «Давай возьмем
все их сильные стороны и реализуем».

Лицензионная рамка: Natively — Personal Use Source License (не OSS), §4.10–11 запрещает
использовать их код/архитектуру/промпты для конкурирующего продукта. Реализация —
clean-room по фич-листу: идеи и названия возможностей, свой дизайн и код.

## What Changes
7 слайсов, порядок — по ценности и независимости (Wave-0: «7 слайсов, без экстра»):

| Слайс | Содержание | R | Спека |
|---|---|---|---|
| **S1** | RAG-память: локальный векторный индекс транскриптов (sqlite-vec), эмбеддинги local-first + опциональный cloud BYOK | R01–R04 | `specs/rag-memory/` |
| **S2** | Стриминговый облачный STT: Deepgram WS первым + единый интерфейс стриминга под остальных; локальный Nemotron остаётся дефолтом | R05–R08 | `specs/streaming-stt/` |
| **S3** | Стелс window-level: скрытие Dock/таскбара, диалогов, тултипов, нотификаций из захвата; без маскировки процесса | R09–R11 | `specs/stealth-window/` |
| **S4** | Дешёвый пак: персоны Sales/Recruiting/Lecture/Call Center (данные), DOCX в загрузчике, экспорт истории md/json | R12–R14 | `specs/cheap-pack/` |
| **S5** | Visual Answers: LLM возвращает схему → рендер через mermaid (уже в бандле), промпт-движок по профилю | R15–R16 | `specs/visual-answers/` |
| **S6** | Дистрибуция: portable-артефакт Windows в существующем CI | R17–R18 | `specs/distribution/` |
| **S7** | Интеграция: финальный oracle по всем слайсам на integration-ветке | все | — |

Манифест с дословными цитатами: `manifest.md` (R01–R21, G1 PASS).

## Границы объёма (согласовано, Wave-0)
- **Вне программы**: Phone Mirror (R19), Browser Companion (R20), Token/Pro-экономика (R21).
- **Вне программы**: mac/linux-матрица, подпись, нотаризация (R18).
- **Вне программы**: маскировка процесса и фейковые иконки (R10).
- **Инварианты**: bundle id, путь `pluely.db`, secure_storage, pubkey апдейтера, имя бинарника;
  локальный Nemotron — дефолтный STT; Free = локальное ядро; trusted-hosts гейт для новых эндпоинтов.

## Capabilities & Impact
- **Capabilities**: `rag-memory`, `streaming-stt`, `stealth-window`, `cheap-pack`, `visual-answers`, `distribution`.
- **Зависимости**: S1 тянет `sqlite-vec` (новая Rust-зависимость, поиск — локально);
  S4 тянет DOCX-парсер (новая npm-зависимость); S2 — новый хост в trusted-hosts.
- **Риски**: размер бандла локальных эмбеддингов (S1 — ленивая загрузка модели);
  EDR-флаги исключены решением R10 (без маскировки процесса).
