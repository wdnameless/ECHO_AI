# Proposal: живой стиль речи и обучение на собеседнике

## Зачем
Три несвязанные боли из одного скрина живой сессии. (1) Ответы покрыты
сырыми `$$`: инструкция модели требует LaTeX, а прод-рендер не подключает
remark-math — `$$15$$ секунд` выводится текстом. (2) Система режет
слова-паразиты юзера перед AI (дефолт фильтра), поэтому ответы не могут
звучать «как я обычно говорю». (3) Советы собеседника («давай углубись в
один пример… отвечай прямо без общих слов») — самый ценный сигнал для
мок-интервью — сейчас никуда не записываются. Плюс скорость/точность:
узкое место неизвестно, чинить вслепую нельзя.

## Что меняется
- **Рендер**: подключить `remark-math` в прод-рендер (уже зависимость
  теста), `$$15$$` рендерится формулой. Санитайзер KaTeX-теги уже
  разрешает; тест — рендер процентов без сырого `$$` в DOM.
- **Фильтр**: `filterAiEnabled` по умолчанию ВЫКЛ — речь юзера идёт в
  модель как есть. Тумблеры остаются для тех, кто хочет резать.
- **Стиль**: два слоя. (а) Расширить пулы живых фраз RU/EN. (б) Считать
  топ-N филлеров юзера из его распознанной речи и умеренно вплетать в
  ответы через evolution-блок. Без фанатизма: кап на плотность.
- **Коучинг**: кнопка на реплике собеседника «Взять как правило» →
  запись в learned rules с `source=coach`, видна в журнале и редакторе.
- **Скорость**: сначала замер по существующим метрикам (ASR-финал,
  flushGap, TTFT) на живой сессии → отчёт с узким местом → только
  потом точечный фикс. Сам фикс — в рамках этой же задачи, если он
  маленький; если большой — отдельной задачей с новой спекой.

## Не входит
- Запрет `$$` в инструкциях модели; автоопределение советов без кнопки;
  агрессивные дефолты скорости без замера; новые провайдеры/режимы.

## Риски
- KaTeX в ленте: формулы тяжелее текста; рендер уже ленивый — ок.
- Филлеры юзера в ответах могут раздражать: кап плотности + кнопка
  самообучения по-прежнему всё гасит целиком.
- Замер скорости требует живой сессии с микрофоном — делает Oracle на
  реальном запуске, либо фиксируем метрики из кода и честно пишем
  «не измерено» по тем, что без живой сессии недоступны.
