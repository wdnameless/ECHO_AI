# Proposal: Plan remainder — дожимаем и релизим

## Why
По плану осталось: 4 latency-пункта (KV-cache, TLS pre-warm, потоковый перевод,
WAL-тест), живой бенчмарк, решение по оплате (принято: выкинуть Pro), гигиена
манифестов. Затем тесты и релиз. Пользователь: «Доделывай, тестируй и публику в релиз».

## What Changes
8 тикетов, 3 фронта (зоны не пересекаются):

| Фронт | Тикеты | Зона |
|---|---|---|
| F1 | T1 (R01 KV-order) + T4 (R04 WAL-тест) | `prompt-builder.ts`, `db/main.rs` тесты |
| F2 | T2 (R02 TLS warm) + T3 (R03 перевод) | Rust `warm` команда, WS-хуки перевод |
| F3 | T5 (R05 бенчмарк) + T6 (R06 no-Pro) + T7 (R07 гигиена) | `scripts/bench/`, entitlements, openspec |

T8 (R08 релиз) — оркестратор сам после oracle.

Спека: `specs/remainder/spec.md` (R01–R07).
Манифест: `manifest.md` (G1 PASS).

## Границы объёма
- Вне: всё deferred ранее (Phone Mirror, Companion, mac/linux).
- Инварианты: поведение 1:1 кроме удаляемого Pro; бенчмарк не ходит в прод-API
  без ключа (локальные метрики + опциональный LLM-судья).
