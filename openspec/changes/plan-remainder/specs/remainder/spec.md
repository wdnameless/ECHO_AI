## ADDED Requirements

### Requirement: KV-стабильный промпт

Статичная часть промпта MUST идти первой и быть байт-стабильной между запросами
при тех же входах; волатильные блоки (язык, evolution, поиск) — в конце.

#### Scenario: Префикс стабилен
- **Given** два запроса с тем же профилем и вопросом, но разным языком ответа
- **When** собираются промпты
- **Then** общий префикс совпадает побайтово до первого волатильного блока

### Requirement: Тёплый TLS к LLM

Команда `warm_llm_connection` MUST открывать соединение до финализации вопроса;
вызов — при старте речи или арме gap-таймера.

#### Scenario: Коннект готов заранее
- **Given** идёт речь собеседника
- **When** вопрос финализируется
- **Then** TLS-рукопожатие уже выполнено (метрика warm RTT записана)

### Requirement: Живой перевод парциалов

Частичные транскрипты MUST переводиться потоково с дебаунсом 400мс вместо спиннера.

#### Scenario: Перевод догоняет речь
- **Given** длинная реплика с включённым переводом
- **When** приходят парциалы
- **Then** перевод обновляется живым текстом, спиннера нет

### Requirement: Подтверждённый WAL

Стартовые PRAGMA MUST покрыты тестом на реальной тестовой БД.

#### Scenario: WAL активен
- **Given** тестовый профиль БД
- **When** применяется инициализация
- **Then** `journal_mode` читается как `wal`

### Requirement: Живой бенчмарк

Корпус из 20+ эталонов + команда `npm run bench` MUST выдавать метрики
точности/скорости без прод-ключей.

#### Scenario: Бенчмарк работает из коробки
- **Given** чистая машина без API-ключей
- **When** запускается `npm run bench`
- **Then** отчёт с метриками по каждому кейсу + итог

### Requirement: Честно бесплатное приложение

Pro-гейты, экраны апгрейда и entitlement-ветки MUST быть удалены; все функции
доступны напрямую.

#### Scenario: Нет следов Pro
- **Given** собранное приложение
- **When** grep по `UpgradePrompt|requirePro|isPro`
- **Then** ноль совпадений в прод-коде (тесты обновлены)
