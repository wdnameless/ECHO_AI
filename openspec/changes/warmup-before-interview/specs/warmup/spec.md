# Spec: warmup-before-interview

## MUST
- Кнопка явная, не скрытый прогрев; готово = движок + провайдер.
- После смены модели кнопка возвращается (рестарт движка убил прогрев).
- Состояние спиннера видно во время работы.

## MUST NOT
- Тихий прогрев без UI; прогрев при старте приложения; RAG TTL > 30с.
