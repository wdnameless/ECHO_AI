# Proposal: прогрев перед собесом

## Зачем
Первый вопрос собеса платит холодный старт целиком: движок, модель,
соединение провайдера, RAG-чтение. По коду: TTFT первого ответа > второго
именно на этом.

## Что меняется
- Кнопка «Прогреть» рядом с RU/EN в панели: движок+модель+провайдер+RAG
  до первого вопроса. Видна до успеха, скрыта после, возвращается после
  смены модели.
- Индикатор «Готовится» на время; готово = движок здоров + провайдер отвечает.

## Не входит
- Авто-прогрев при старте приложения; прогрев при startCapture без кнопки;
  RAG TTL дольше 30с (контекст редактируется — кэш краткий намеренно).
