# Proposal: скриншот → код

## Зачем
Кодовый путь отвечал только на текст: «почини» без свежего вопроса + код на
экране уходил в модель вслепую. Лайв-кодинг — 80% собеса, дебаг чужого кода
на экране — его половина.

## Что меняется
- Третья кнопка «Код со скрина» в код-ряду: захват (`capture_to_base64`) +
  вопрос из истории (`findCodeRequestInHistory`) → модель.
- Скриншот форсит модельный путь: template-match больше не возвращает раньше
  времени и не роняет скриншот. Vision-правило в code-промпте (прочитай,
  разбор, fence с табами, нарратив).
- Рендер тем же `splitCodeAnswer`/`CodeAnswerBody`: fence + кнопка «Код».
- Без vision у провайдера — честная ошибка провайдера, не тишина.

## Не входит
- Локальный OCR-движок; выбор области экрана (весь экран); история скриншотов.
