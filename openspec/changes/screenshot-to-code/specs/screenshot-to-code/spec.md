# Spec: screenshot-to-code

## MUST
- Скриншот никогда не роняется молча: template-match не обходит модель при скриншоте.
- Вопрос — из истории диалога, скриншот — свежий захват.
- Ответ рендерится тем же код-блоком с копией сниппета.

## MUST NOT
- Локальный OCR; выбор области; история скриншотов; тихий дроп скриншота.
