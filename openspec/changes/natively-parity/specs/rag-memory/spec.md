## ADDED Requirements

### Requirement: Векторная память встреч

Транскрипты завершённых встреч MUST индексироваться в локальное векторное хранилище,
чтобы пользователь мог искать по прошлым встречам вопросом на естественном языке.
Поиск MUST выполняться локально, без отправки транскриптов наружу.

#### Scenario: Поиск по прошлой встрече находит ответ
- **Given** проиндексирована встреча, где Джон обсуждал API
- **When** пользователь спрашивает «что Джон говорил про API?»
- **Then** поиск возвращает релевантный фрагмент с идентификатором встречи

#### Scenario: Существующий RAG-контекст не ломается
- **Given** у пользователя настроены резюме и вакансия
- **When** RAG-память включена и работает
- **Then** тумблеры резюме/вакансии продолжают подставлять контекст как раньше

### Requirement: Гибридные эмбеддинги

Эмбеддинги MUST быть локальными по умолчанию; облачный BYOK-бэкенд MUST включаться
только явной настройкой пользователя с его ключом.

#### Scenario: Дефолт работает офлайн
- **Given** свежая установка без облачных ключей
- **When** встреча завершается
- **Then** индексация выполняется локальной моделью без сетевых запросов

#### Scenario: Cloud-бэкенд опционален
- **Given** пользователь ввёл ключ эмбеддинг-провайдера и выбрал cloud
- **When** встреча завершается
- **Then** эмбеддинги считаются через API, а векторный поиск остаётся локальным
