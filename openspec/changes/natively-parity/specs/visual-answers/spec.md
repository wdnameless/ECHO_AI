## ADDED Requirements

### Requirement: Диаграммы в ответах

Когда вопрос подразумевает схему (архитектура, поток, последовательность), ответ
MUST мочь содержать диаграмму, отрендеренную через mermaid-движок из бандла.

#### Scenario: Системный дизайн рисуется схемой
- **Given** профиль Livecode/Interview и вопрос «спроектируй URL-shortener»
- **When** ответ сгенерирован
- **Then** в ленте видна отрендеренная схема, а не только текст

#### Scenario: Обычные ответы не ломаются
- **Given** вопрос без визуальной составляющей
- **When** ответ сгенерирован
- **Then** ответ — обычный текст без пустых диаграмм-заглушек
