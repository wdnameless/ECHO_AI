## ADDED Requirements

### Requirement: Portable-артефакт Windows

CI MUST собирать portable-артефакт Windows рядом с MSI/NSIS: распаковал и запустил,
без установщика, с обновлениями через существующий канал.

#### Scenario: Portable запускается без установки
- **Given** собранный portable-артефакт из CI
- **When** пользователь распаковывает и запускает его
- **Then** приложение работает с изолированным профилем рядом с бинарником

#### Scenario: Обычный установщик не ломается
- **Given** изменённый workflow
- **When** CI собирает релиз
- **Then** MSI/NSIS-артефакты собираются как раньше, portable — дополнительно
