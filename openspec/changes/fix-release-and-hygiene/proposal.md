# Proposal: релиз без гонок, одна версия, чистые ветки

## Зачем
Пуш тега и merge в master для одной версии проходили `check` параллельно и
роняли второй ран после полной Tauri-сборки. `--verify-tag` падал на каждом
веточном пуше с новой версией, потому что локального тега там нет. Версия жила
в трёх файлах руками. 13 мёртвых веток засоряли репо.

## Что сделано
- `release.yml`: `concurrency: group: release` + убран `--verify-tag`.
- `scripts/bump-version.mjs`: истина — `tauri.conf.json`, синк двух остальных.
- `.gitignore`: 751-МБ `.gguf`, `/backups/`, `asr-port` вне индекса.
- R04–R09 аудита: код уже содержал фиксы, tasks.md помечен, тесты зелёные.
- Ветки: удалены все слитые/превосходящиеся; `feat/filler-removal` и
  `origin/fix/portable-update-notice` оставлены осознанно (уникальные diff).

## Не входит
- Переписывание истории `.git` (LFS-миграция движка) — отдельный риск, не трогали.
- Cherry-pick `fa87356` (филлеры) и `2987181` (portable notice) — следующие слайсы.
- Matrix-сборки под macOS/Linux — осознанно только `windows-latest`.
