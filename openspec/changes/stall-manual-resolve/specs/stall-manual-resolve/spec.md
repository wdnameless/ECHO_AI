# Spec: stall-manual-resolve

## MUST
- Ни одной авто-ошибки за тишину: ни строки в ответ, ни авто-фолбэка.
- Сентинел никогда не попадает в текст ответа, копию, историю.
- «Другой» не меняет глобальный выбор провайдера (one-off).
- Аборт закрывает зависший стрим как раньше (стоп/новый вопрос/unmount).

## MUST NOT
- Второй авто-таймаут; авто-повтор; тихая сдача; смена глобального
  провайдера из баннера; строка-ошибка внутри ответа.
