# Proposal: полная оптимизация ASR (скорость + точность, RU/EN)

## Зачем
Главная боль — скорость и точность на двух языках. Один универсал (Nemotron
WER 3.05) проигрывает паре моно-моделей; VAD-пороги Low/Normal/High не покрывают
тихий кабинет с хорошим микрофоном; batch-каданс 300мс оставляет −50мс на столе;
EN тащит Q8 без нужды (запас WER 1.6); переключать RU/EN мышью mid-call медленно.

## Что меняется
### R01: пресеты Студия/Офис/Шумно + слайдеры gate/sensitivity/min_speech
- `SENSITIVITY_PRESETS` → `studio` (gate 0.0015, sens 0.008, peak 0.025,
  min_speech 5 — цепляет тихие начала, шума нет = галлюцинаций нет),
  `office` (= нынешний normal), `noisy` (= low + min_speech 9).
- `getCurrentPreset`/`handlePresetChange` — по 5 полям (добавлены min_speech,
  silence оставлен ручным).
- Advanced: слайдеры Noise Gate (есть) + Speech Sensitivity (есть) +
  **новый Min Speech** (3–15 чанков, подсказка «короче = цепляет тихое,
  длиннее = режет мусор»). Silence-слайдер min 20→8 (баг: дефолт 12
  невосстановим), `handleResetDefaults` — из `DEFAULT_VAD_CONFIG`, не хардкод.
- Ответ на вопрос пользователя: да, gate вниз при хорошем микрофоне = меньше
  «Yeah.» и лучше начала фраз. Но gate 0 = движок слышит шум как речь, поэтому
  Студия = низкий gate + низкий min_speech ПАРОЙ, а не gate в ноль.

### R02: хоткей Ctrl+Shift+L + сегмент
- `code_mode` образец: новый `lang_switch` в `DEFAULT_SHORTCUT_ACTIONS`
  (ctrl+shift+l везде) → Rust `custom-shortcut-triggered` → тот же
  `switchTo` с локом `switching` (двойные нажатия игнорятся).
- Сегмент RU/EN уже в тулбаре (прошлый слайс) — хоткей его дублирует.

### R03: Q4 для EN, Q8 для RU
- `useSpeechModelSwitch`: EN ищет сначала `Q4_K_M`-файл (`-Q4_K_M.gguf`),
  fallback Q8; RU — строго Q8. `downloadModel(id, quant)` уже умеет квант —
  Модели-страница докачивает нужный.
- Каталог не правим (default_file общий); выбор кванта — в свитче.

### R04: баланс — каданс 250мс, остальное не трогаем
- `LIVE_BATCH_MS` 300→250 (замер: запас 2–5x над стоимостью прохода; 250
  оставляет ~1.4x на патологиях; `liveBusyRef` дропает наложение).
- VAD `silence_chunks: 12` НЕ трогаем (режет вопросы), `flushGapMs` НЕ трогаем.
- Scrub + energy-gate связка уже есть (прошлый слайс) — не дублируем.

## Не входит
- Два движка одновременно; авто-детект языка реплики; GigaAM-подключение;
  облачный STT-фолбэк; смена дефолтного кванта в каталоге.

## Риски
- 250мс на слабом CPU: проходы начнут дропаться (`liveBusyRef`) — текст
  придёт реже, но не сломается. Откат — одна константа.
- Студия-пресет на шумной кухне = галлюцинации вернутся; пресет подписан
  честно («тихо + хороший микрофон»).
