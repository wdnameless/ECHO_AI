# Spec: asr-full-optimize

## MUST
- Пресет Студия цепляет тихие начала без галлюцинаций в тишине; Шумно режет мусор.
- Слайдеры двигают реальный конфиг движка (инвок update_vad_config).
- Хоткей тоглит RU/EN mid-call; двойное нажатие не ломает движок.
- EN грузится из Q4-файла при наличии; RU всегда Q8.
- Каданс 250мс не роняет проходы на типовом железе.

## MUST NOT
- Gate в ноль отдельным слайдером (шум = речь для движка).
- Авто-скачивание Q4 без спроса; смена дефолта каталога.
- Трогать silence_chunks дефолт и flushGapMs.
