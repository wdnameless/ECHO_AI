## Why
На СБС спрашивают ход мыслей кандидата. Нужен тумблер компактного обоснования поверх обычного ответа и отдельный голосовой лайвкодинг-режим. Плюс полный аудит пайплайна вопрос→ответ: разведка уже нашла 8 блокеров режимов и 8 прочих багов.

## What Changes
- Тумблер «Ход мыслей»: компактное обоснование в той же ленте, humanizer/длина не душат.
- Тумблер «Лайвкодинг»: голосовая задача → диктуемый код с устным объяснением, через существующие code-промпты.
- Аудит-отчёт с ранжированными находками; блокеры режимов чинятся в их слайсах.

## Capabilities
### New Capabilities
- `thought-trace-mode`: компактное обоснование в ленте по тумблеру.
- `voice-livecoding-mode`: голосовой код с объяснением по тумблеру.
- `pipeline-audit-report`: ранжированный отчёт по архитектуре.
