# Spec: dualmodel-fillers-length

## MUST
- RU/EN сегмент переключает МОДЕЛЬ движка (рестарт), не только язык; без
  скачанной модели — CTA, не тихая подмена.
- Перебивка — первая строка тела ответа, живёт весь ответ.
- Детальный вопрос → длинный ответ; `кратко:`/`подробно:` и кнопки перебивают.
- 5 ответов подряд — без одинаковых заходов.

## MUST NOT
- Авто-детект модели по реплике; авто-скачивание гигабайтов.
- clearFiller, стирающий сшитую перебивку из тела.
- Зашитый 35–55 для всех ответов; «Ну, смотрите» каждый раз.
