# Proposal: двойная streaming-модель, persistent перебивки, адаптивная длина

## Зачем
Три жалобы с живого собеса: (1) язык путается — одна модель на два языка;
(2) перебивка исчезает с первым токеном — прочитать нельзя; (3) ответы всегда
короткие 35–55 слов и всегда с «Ну, смотрите» — паттерн палит.

## Что меняется
### R01: RU/EN сегмент — выбор streaming-модели, не языка распознавания
- Сегмент RU/EN рядом с Авто/Вручную в тулбаре панели (`speech/index.tsx`).
- Состояние: `speechModelLang: "ru" | "en"` (localStorage `speech_model_lang`).
- Выбор = `selectModel(path)` + `setAsrLanguage(lang)` + сброс кэшей. Пути:
  RU → `Voxtral-Mini-4B-Realtime-2602` (единственная streaming с `ru`, WER 2.07,
  2.6–4.4 ГБ); EN → `parakeet-unified-en-0.6b` (WER 1.6, ~700 МБ).
- Если файл модели не скачан — кнопка показывает «Скачать в Моделях» и ведёт
  на `/models` (никакой тихой подмены, никакого авто-даунлоада гигабайтов).
- Гонки: лок `switchingRef`, игнор кликов пока идёт переключение; перед
  `selectModel` — закрыть оба WS и `releaseStream`, иначе рестарт убивает
  открытый стрим.
- Честно: RU-стриминга лёгкого нет — Voxtral 4B требует VRAM/RAM. Если не
  влезет — fallback на batch Parakeet-TDT с пином `ru` (без партиалов, но
  точно и быстро ~64мс). Это сказать в UI, а не молчать.

### R02: перебивка — первая строка ответа
- `processWithAI` на первом чанке НЕ `clearFiller`, а `stitchFiller`: текст
  ответа = `filler + "\n\n" + stream`. `clearFiller` остаётся в `finally`/
  abort/error — состояние чистится, тело ответа нетронуто.
- `StreamingAiRow`/`AiFeedRow` рендерят как есть (filler уже внутри текста).
- Баннер-заглушка «Заполните паузу» остаётся только пока `lastAIResponse`
  пуст (до первого токена) — дальше filler живёт в теле.

### R03: адаптивная длина — эвристика + оверрайд
- `classifyLength(question): "short" | "long"` (`src/lib/answer-length.ts`):
  long при `?` + длине >60 ИЛИ маркерах (почему/зачем/сколько/разница/
  сравни/подробно/пошагово/explain/compare/why/how much); префикс
  `подробно:`/`кратко:` (и `long:`/`short:`) — жёсткий оверрайд.
- Кнопки Кратко/Подробно в тулбаре (`answerLengthOverride: auto|short|long`),
  префикс чистится из вопроса перед отправкой.
- Промпт: short → текущий hard-cap 35–55 слов; long → до ~140 слов, детали
  разрешены, структура — связный монолог (НЕ списки — устная речь).
- `INTERVIEW_MODE_INSTRUCTIONS` KEEP CONCISE переписывается: лимит выбирается
  динамически, а не зашит.

### R04: пул заходов 12+12 с ротацией
- `ANSWER_OPENERS_RU/EN` в `humanizer.rules.ts` (12+12, без «Ну, смотрите» как
  дефолта — он один из, не каждый), `pickOpener(lang)` с `lastOpenerRef`
  (без повтора подряд), часть — прямой старт без вводной.
- Промпт: «открой ОДНИМ из списка, не повторяй предыдущий» вместо захардкоженных
  3 примеров (которые модель и копировала).

## Не входит
- Авто-выбор модели по языку реплики; скачивание моделей из панели;
  тренажёр; два движка одновременно (один selectModel за раз).
- Смена 35–55 дефолта для code-режима (у него свой промпт).

## Риски
- Voxtral 4B может не влезть на слабом железе → честный fallback, не молча.
- Stitch filler меняет `addInteraction` (тело с filler): история хранит ответ
  как показан — это и есть «диалог сохраняется», ок.
- Длина long вдвое дороже по токенам/TTFT — цена детализации, видна в футере.
