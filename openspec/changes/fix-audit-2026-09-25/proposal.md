# Fix all audit findings — Echo AI (2026-09-25)

## Why

Четыре независимых read-only ревьюера + верификация оркестратором нашли 28
дефектов в 37k TS и 9.5k Rust: от воспроизводимой потери данных до мёртвого
пайплайна распознавания, который UI продолжает показывать живым.

## What changes

Исправление в порядке приоритета аудита. Полный реестр требований с дословными
цитатами — `manifest.md`; границы и инварианты слайсов — `interfaces.md`.

- **P0 (данные/пайплайн)**: чат >100 сообщений больше не стирается при
  сохранении; тишина 3 с не убивает захват системного звука навсегда; зависший
  sidecar перезапускается watchdog'ом.
- **P1 (неверные ответы/утечки/блокировки)**: история диалога уходит в LLM в
  хронологическом порядке; выход не блокирует UI до 8 с; удаление лицензии
  сначала освобождает место на сервере; слушатели и сокеты снимаются на unmount;
  сохранение не теряет сообщения, пришедшие во время записи; ключ не сохраняется
  обрезанным; секреты не уходят на хост после редиректа; речь с «HTTP 404» не
  выбрасывается; Linux-коррекции и SQL работают с одной БД; ключи не лежат
  открытым текстом.
- **P2 (стоимость/мусор)**: контекст и фид не перерисовываются на каждый токен;
  barrel не тянет recharts/cmdk в 77 модулей; дублирование `useCompletion` /
  `useChatCompletion` устранено; portable-режим не включается молча; захват не
  берёт мьютекс на сэмпл; мёртвый `FillerManager` убран; визуализатор очищается.

## Out of scope

- Новые фичи и внешние зависимости.
- Пункты, отклонённые в аудите (`models.rs:333`, `vocab.rs` на Windows,
  `activate.rs:347`, `db/main.rs:135`) — оставлены как есть осознанно.

## Acceptance

- Полный `vitest` зелёный; добавленный регрессионный тест на 150 сообщений
  падает до фикса и проходит после.
- `cargo test` зелёный; `tsc --noEmit` чистый.
- Сборка `vite build` без ошибок; стартовый payload не вырос.
- Blind oracle по манифесту (двойная приёмка — модель flash-класса).
