# Requirements Manifest — филлеры, обучение на речи, скорость

Бриф дословно: «в ответах почему то знаки по типу $$» + «нужно добавить больше слов паразитов чтобы было похоже на человека» + «увеличить точность и скорость» + «наша система не вырезала слова паразиты, и обучалась на них и пыталась давать ответ в свободной форме так как я обычно говорю» + «система self evolution обучалась на ответе собеседника если он дает какие то рекомендации» + «я буду проходить много мок интервью».
Решения Wave 0 — виджет ниже.

| ID | Требование | Дословная цитата | Статус |
|----|-----------|------------------|--------|
| R01 | Убрать артефакты `$$` в ответах, починив рендер | «в ответах почему то знаки по типу $$» + «Оставить $$, чинить рендер» | in-spec |
| R02 | Не вырезать слова-паразиты по умолчанию | «наша система не вырезала слова паразиты» + «Выключить вырезание» | in-spec |
| R03 | Больше слов-паразитов + обучение на речи юзера | «нужно добавить больше слов паразитов чтобы было похоже на человека» + «Оба» | in-spec |
| R04 | Ответы в свободной форме, как говорит юзер | «пыталась давать ответ в свободной форме так как я обычно говорю» | in-spec |
| R05 | Self-evolution учится на рекомендациях собеседника | «система self evolution обучалась на ответе собеседника если он дает какие то рекомендации» + «Вручную кнопкой» | in-spec |
| R06 | Увеличить точность и скорость, сначала замер | «нужно как то увеличить точность и скорость» + «Сначала замер, потом фикс» | in-spec |
| R07i | Мок-интервью как главный сценарий: советы собеседника — первоклассный сигнал | implicit из «я буду проходить много мок интервью» | in-spec |

## Явно ВНЕ скоупа
- Запрет `$$` для чисел в инструкциях модели (отклонено выбором «чинить рендер»).
- Автоопределение советов собеседника без кнопки (отклонено: «Вручную кнопкой»).
- Агрессивные дефолты скорости без замера (отклонено: «Сначала замер»).
