# Spec: livecode-stealth

## MUST
- Кодовый режим включается только вручную (кнопка/хоткей), обычный вопрос
  режим не переключает.
- Первый ответ — 1 фраза-план; фрагмент кода — только по явному запросу.
- Фрагмент — plain code block, перепечатываемый руками, без humanizer-заходов.
- Opacity 20–100%, босс-кей прячет ВЕСЬ оверлей включая панель, Esc прячет.
- 12 шаблонов покрывают типовые задачи собеса (debounce … LRU).

## MUST NOT
- Авто-детект кодовых вопросов (ложные срабатывания на теории).
- Humanizer-инструкции внутри кодового ответа.
- Босс-кей, оставляющий панель на экране.
- Тренажёр/оценка в этом слайсе.
