# Proposal: лайв-кодинг режим + анти-детект

## Зачем
80% техсобеса — лайв-кодинг (React с нуля, дебаунс, оптимизации), а Echo отвечает
только устным монологом 35–55 слов. Кандидат остаётся один на один с редактором.
Плюс подсказка должна быть невидимой: прозрачность, босс-кей, быстрый хайд.

## Что меняется
### Кодовый режим (R01, R02, R04)
- Кнопка «Код» в баре + хоткей `code_mode` (дефолт `ctrl+shift+k`). Только ручной
  вызов, никакого авто-детекта.
- Первый ответ — 1 фраза-план («Пишем дебаунс на 300мс с cleanup»). По запросу
  (кнопка «Показать код» / повторный хоткей) — готовый фрагмент + 2–3 фразы
  объяснения для проговаривания вслух.
- `src/lib/code-templates.ts`: 12 шаблонов (debounce, throttle, fetch+retry,
  список+поиск, memo, группировка, скобки, Promise.all/race, рефакторинг
  React-модуля, shallow equal, emitter, LRU). Совпадение по ключевым словам —
  подмешать шаблон в системный промпт как образец; иначе — чистый code-промпт.
- Code-промпт: plain code block + короткое объяснение, БЕЗ humanizer-болтовни
  (инструкции humanizer подавляются для кода — иначе ломают отступы и добавляют
  «Слушайте, на прошлом проекте» внутрь ответа).
- Кулдаун 2с из `useAIStreaming` не применяется к ручному кодовому вызову.

### Стелс (R03)
- Слайдер opacity 20–100% в баре → `useTheme().onSetTransparency(100 - opacity)`,
  clamp `transparency` 0–80. Применяется и к `.panel-docked` (сейчас `--opacity`
  до него не доходит — чинится в `global.css`).
- Босс-кей уже есть: `toggle_window` (`ctrl+backslash`) — документируется в UI,
  без нового кода. Чинится инверсия `setIsHidden(!payload)` в `useApp.ts:85`
  и рассинхрон с Rust `WindowVisibility.is_hidden`.
- Esc-хайд: keydown в баре → `setIsHidden(true)`, уступает место Esc в
  continuous-recording и инлайн-редактировании.

## Не входит
- Тренажёр/банк задач с оценкой (отдельный слайс, R05).
- Авто-детект кодовых вопросов.
- Новые Rust-команды (всё на существующих).

## Риски
- Humanizer против кода: подавляем `HUMANIZER_INSTRUCTIONS` + interview-опенеры
  в code-промпте, иначе «живой заход» попадёт в копируемый фрагмент.
- `isHidden` не прячет `.panel-docked` (портал в body): хайд должен идти через
  window.hide или CSS-класс на портале, иначе босс-кей прячет бар, а панель
  остаётся на экране — полный провал стелса.
