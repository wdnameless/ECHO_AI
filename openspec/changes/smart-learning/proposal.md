# Proposal: Smart learning + Settings UX

## Why
«Взять как правило» кладёт сырую реплику собеседника (с ASR-мусором) целиком в
промпт как вечное правило: нет извлечения смысла, подтверждения, редактуры,
веса, смерти правил и детекта противоречий. Настройки профилей — 1363 строки в
одном файле-стене. Пользователь: «делай» + «нормальный UI UX».

Wave-0: гибридное извлечение, полный жизненный цикл, слой поведения, полный
редизайн настроек, миграция «перенести всё».

## What Changes
6 тикетов, 4 фронта (зоны не пересекаются):

| Фронт | Тикеты | Зона |
|---|---|---|
| F1 | T1 (R01–R02 извлечение+превью) | новый `rule-extract.ts` + `SubtitleFeed` превью |
| F2 | T2 (R03–R06 модель+миграция) | `user-facts.ts` (модель правил), миграция |
| F3 | T3+T4 (R07 поведение, R08 поповер) | новый `behavior-watch.ts` + поповер Self-Evolution |
| F4 | T5 (R09–R12 редизайн) | `PromptProfilesSettings.tsx` → модули |

Порядок: F2 первым (модель нужна всем), затем F1+F3+F4 параллельно.
T5 зависит от T2 (правила с весом в UI).

Спеки: `specs/smart-rules/spec.md` (R01–R08), `specs/settings-ux/spec.md` (R09–R12).
Манифест: `manifest.md` (R01–R12, G1 PASS).

## Границы объёма
- Вне: новые провайдеры LLM, серверная аналитика, шаринг правил.
- Инварианты: существующие операции настроек сохранены (R11); контекст API
  (`select/update/create/delete/resetPromptProfile`) не меняется; промпт-блок
  обратно совместим (пусто при выключенном обучении).
