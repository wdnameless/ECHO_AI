## ADDED Requirements

### Requirement: Карточки профилей и мастер

Профили MUST показываться карточками (имя, описание, бейджи); создание — мастером
в 3 шага (название → промпт → кнопки/тайминги).

#### Scenario: Создание за 3 шага
- **Given** пользователь жмёт «Новый профиль»
- **When** проходит 3 шага мастера
- **Then** профиль создан, каждый шаг показывает только свои поля

### Requirement: Правила с весом и превью

Экран правил MUST показывать вес/хиты/источник; экран профиля MUST показывать
превью собранного промпта.

#### Scenario: Промпт виден до сохранения
- **Given** редактируемый профиль с правилами
- **When** открыт превью-режим
- **Then** виден итоговый системный промпт как его увидит модель

### Requirement: Сохранение операций и модули

Все CRUD/импорт/экспорт/факты/USER.md/сброс MUST работать; монолит MUST быть
разбит на модули по экранам.

#### Scenario: Старые операции на месте
- **Given** новый экран настроек
- **When** пользователь ищет экспорт, факты, сброс
- **Then** всё находится и работает, тесты зелёные
