## ADDED Requirements

### Requirement: Превью извлечённого правила

Взятие MUST показывать нормализованную форму (инфинитив, ≤12 слов, без
обращений и ASR-мусора) с действиями Сохранить / Править / Отмена. Эвристики
MUST давать результат мгновенно офлайн; LLM MUST улучшать формулировку фоном.

#### Scenario: Мусор не попадает в правило
- **Given** реплика «Ну, кстати, давай углубись в один пример, отвечай прямо»
- **When** пользователь жмёт «Взять как правило»
- **Then** превью показывает «углубляться в один пример, отвечать прямо» и ждёт подтверждения

#### Scenario: Отмена ничего не пишет
- **Given** открытое превью правила
- **When** пользователь жмёт Отмена
- **Then** правило не сохраняется, лог не засоряется

### Requirement: Жизненный цикл правил

Каждое правило MUST иметь вес, область, счётчик срабатываний, TTL; мёртвые
MUST архивироваться; противоречия MUST спрашивать замену.

#### Scenario: Противоречие спрашивает
- **Given** правило «отвечай коротко» и новое «давай подробно»
- **When** сохраняется новое
- **Then** UI спрашивает заменить/оставить оба, молчаливого соседства нет

#### Scenario: Мёртвое архивируется
- **Given** правило с весом 0 и 30 днями без срабатываний
- **When** проходит обслуживание
- **Then** правило уходит в архив, из промпта исчезает

### Requirement: Миграция старых правил

Строковые customRules MUST мигрировать в объекты (вес 1.0, глобально) без потерь.

#### Scenario: Обновление не теряет правила
- **Given** 5 строковых правил до обновления
- **When** открывается новая версия
- **Then** все 5 на месте как объекты с весом 1.0

### Requirement: Предложения из поведения

Повторяющиеся паттерны MUST предлагать правило; запись — только после подтверждения.

#### Scenario: Три укорачивания предлагают правило
- **Given** пользователь 3 раза подряд укорачивает ответ вручную
- **When** детектор видит паттерн
- **Then** появляется предложение «отвечать короче?» с Да/Нет

### Requirement: Объяснимые правила в поповере

Поповер MUST показывать источник, хиты, вес; удаление — в один клик.

#### Scenario: Правило объяснимо и убиваемо
- **Given** правило из реплики 14:32, сработало 12 раз
- **When** открыт поповер Self-Evolution
- **Then** видны источник/хиты/вес и кнопка удаления
