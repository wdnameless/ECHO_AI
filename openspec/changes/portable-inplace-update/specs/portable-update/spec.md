# Spec: portable-inplace-update

## MUST
- Портативная копия обновляется одной кнопкой, без ручного скачивания zip.
- Файлы приложения заменяются; `.echo-ai/` (модели, настройки, движок, БД)
  переживает обновление побайтово.
- Обычная (установленная) копия обновляется как раньше через MSI/NSIS.
- Без подписи zip обновление не ставится (fail-closed через updater).

## MUST NOT
- Не трогать `.echo-ai/` при распаковке (ни удаление, ни перезапись).
- Не запускать MSI/NSIS из портативной копии.
- Не врать в UI: текст предупреждения = реальное поведение кнопки.
