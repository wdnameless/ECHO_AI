## ADDED Requirements

### Requirement: Хранение учётных данных в защищённом хранилище

API-ключи провайдеров и ключи веб-поиска MUST храниться в защищённом хранилище операционной системы, а не в открытом виде в localStorage.

#### Scenario: Ключ провайдера не лежит в localStorage
- **Given** пользователь сохранил API-ключ AI- или STT-провайдера
- **When** состояние localStorage проверяется
- **Then** значение ключа в localStorage отсутствует

#### Scenario: Ключ поискового сервиса не лежит в localStorage
- **Given** пользователь сохранил ключ веб-поиска
- **When** состояние localStorage проверяется
- **Then** значение ключа в localStorage отсутствует

### Requirement: Сохранение работоспособности провайдеров

Перенос секретов MUST NOT нарушать работу настроенных провайдеров и результатов веб-поиска.

#### Scenario: Провайдер с ключом продолжает работать
- **Given** API-ключ перенесён в защищённое хранилище
- **When** пользователь отправляет запрос к этому провайдеру
- **Then** запрос выполняется успешно с корректным ключом

#### Scenario: Веб-поиск с ключом продолжает работать
- **Given** ключ поискового сервиса перенесён в защищённое хранилище
- **When** пользователь выполняет поиск
- **Then** поиск выполняется успешно

### Requirement: Миграция без потери настроек

Существующие сохранённые ключи MUST быть перенесены в защищённое хранилище без потери настройки провайдеров.

#### Scenario: Обновление сохраняет настройки пользователя
- **Given** пользователь имеет настроенный провайдер с ключом в старом хранилище
- **When** приложение обновляется и запускается впервые
- **Then** ключ переносится в защищённое хранилище
- **And** настройка провайдера остаётся работоспособной
- **And** ключ удаляется из старого хранилища

#### Scenario: Повторный запуск не ломает состояние
- **Given** миграция уже выполнена
- **When** приложение запускается снова
- **Then** настройки остаются неизменными
- **And** повторное копирование не выполняется

### Requirement: Недопущение утечки секретов в логи

Секреты MUST NOT попадать в логи приложения, консольные сообщения и текст ошибок.

#### Scenario: Ошибка запроса не раскрывает ключ
- **Given** запрос к провайдеру завершился ошибкой
- **When** формируется сообщение об ошибке или запись в лог
- **Then** значение API-ключа в них отсутствует
