## Блокеры, вскрытые при выполнении

| Что | Статус | Доказательство |
|---|---|---|
| R25: автообновление | **unmet** | Репозиторий `wdnameless/ECHO_AI` приватный, `releases/latest/download/latest.json` отдаёт **404** анонимно. `tauri-plugin-updater` не передаёт токен (`updater.rs:115` — заголовки пусты по умолчанию), поэтому обновление не сможет получить манифест ни у одного пользователя. Требуется решение: сделать репозиторий публичным либо убрать фичу обновления из UI. |
| Сужение `http:default` до списка доменов | deferred | `tauri-plugin-http` пересобирает scope из статического ACL при каждом вызове (`commands.rs:182-217`) и не имеет `scope()/scope_mut()` (`lib.rs:29`), в отличие от `tauri-plugin-fs` (`lib.rs:367-381`). Runtime-allowlist для подтверждённого хоста невозможен без форка плагина, поэтому сужение ACL сломало бы кастомных провайдеров до показа диалога — см. `s2-http-scope/design.md`. Защита реализована на уровне приложения. |
| Обработчик диалога доверия хостов | done (изменение) | `HostTrustProvider` смонтирован в `main.tsx`, поэтому шлюз не остаётся в fail-closed при обычной работе. |

## Пост-аудит: исправлено после приёмки (2026-09-15)

Повторная проверка после мерджа S1–S6 нашла требования, закрытые фиктивно, и регрессии,
внесённые самим ребрендингом. Каждая правка сопровождается тестом.

| id | Что было | Что сделано |
|---|---|---|
| R03 | **Санитайзер не исполнял allowlist.** Ветка «тег вне allowlist» возвращала `SKIP`, не удаляя узел и не обходя потомков, поэтому `<details><img onerror=…>` и `<svg><foreignObject><img onload=…>` доносили живой обработчик до DOM. Тест «never leaves any attribute starting with 'on'» этого не ловил. | Обход переписан на рекурсивный (`sanitizeChildren`): решение по потомкам принимается до возврата, «обёртки» разворачиваются с подъёмом проверенных детей. 4 регрессионных теста, из них 3 падали на старой версии. |
| R09 | **Ключи веб-поиска оставались в открытом localStorage.** `web-search.ts` не участвовал в S4: `braveApiKey`/`exaApiKey`/`tavilyApiKey` читались и писались напрямую в `web_search_settings`, `getSecret(secretKey.webSearch(...))` не вызывался нигде. | Ключи вынесены в защищённое хранилище (`getWebSearchKey`/`setWebSearchKey`), секретные поля удалены из публичного типа настроек, `saveWebSearchSettings` их отбрасывает, legacy-ключи переносятся при первом чтении. 5 тестов. |
| R09 | **Ключ AI/STT-провайдера попадал в localStorage.** Ввод в `Providers.tsx` писал ключ в `selectedAIProvider.variables`, а эффект сериализовал провайдера целиком в `SELECTED_AI_PROVIDER`. Чтение из хранилища срабатывало только когда переменная пуста. | Обе панели (AI и STT) читают и пишут ключ только через `secret-store`. `fetchProviderModels` берёт ключ из хранилища как fallback. |
| R11 | **Ключ лицензии писался в лог.** `api.rs`: `tracing::debug!("Reporting API error: {:?}", payload)` печатал payload с `license_key` целиком. | Лог перечисляет только endpoint/model/provider/instance. |
| R13 | **`move_window` оставался Pro-гейтом.** Гейт сняли из `start_move_window`, но он остался в `update_shortcuts`: в release без лицензии хоткеи перемещения окна не регистрировались. | Гейт убран; логика планирования вынесена в чистую `plan_shortcut_registrations`, покрытую 3 тестами (в т.ч. «регистрируется без лицензии»). |
| R16/R17 | Selection Mode гейтился прямым `!hasActiveLicense`, hosted API — тоже. | Оба идут через реестр: `canUseFeature("selectionMode")` / `canUseFeature("hostedApi")`. |
| R20 | **Ребрендинг не был завершён:** 10 пользовательских строк остались со старым именем; ссылки в UI вели на несуществующий репозиторий (404). | Все пользовательские строки, README, дескрипторы и issue-шаблоны — на Echo AI. Ссылки в UI переведены на `wdnameless/ECHO_AI`. Защищённые идентификаторы не тронуты (проверено отдельным прогоном). |
| — | **Регрессия от S5:** префикс ошибки STT переименовали в `stt.function.ts` и `stt-fallback.ts`, но `useSystemAudioCapture.ts` и `mock-interview/index.tsx` сравнивали строку со старым `"pluely stt error"`. Ошибки STT попадали в живые субтитры и в контекст mock-interview как реплики собеседника. | Префикс вынесен в константу `STT_ERROR_PREFIX` + типобезопасный `isSttErrorMessage`; все четыре места используют его. 4 теста на контракт. |
| R16 | В реестре возможностей `fonts` не имел ни одной точки вызова — классификация есть, гейта нет. | Оставлено как есть: отдельного контрола шрифтов в UI нет, поэтому гейтить нечего. Зафиксировано, чтобы «мёртвый» элемент реестра не считался закрытым требованием. |
