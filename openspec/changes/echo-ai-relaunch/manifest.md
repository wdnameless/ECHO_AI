### Безопасность

| id | Требование | Цитата-источник | Статус | Слайс |
|---|---|---|---|---|
| R01 | Строгий CSP вместо `csp: null`, закрывающий исполнение инъецированного скрипта в WebView | «Средний: CSP + санитайзер + http-права» | done | S1 |
| R02 | AI-ответы и результаты веб-поиска рендерятся без интерпретации raw HTML | «Убрать rehype-raw + свой allowlist» | done | S1 |
| R03 | Санитайзер блокирует `script`/`iframe`/`object`/`embed` и все `on*`-атрибуты как второй слой | «Убрать rehype-raw + свой allowlist» | done | S1 |
| R04 | mermaid, KaTeX, таблицы, shiki продолжают работать после отключения raw HTML | «Средний: CSP + санитайзер + http-права» | done | S1 |
