## ADDED Requirements

### Requirement: Название продукта Echo AI

Продукт MUST отображаться пользователю под именем «Echo AI» во всех пользовательских точках контакта.

#### Scenario: Заголовок окна показывает название продукта
- **Given** приложение запущено
- **When** пользователь видит заголовок окна и панель навигации
- **Then** отображается «Echo AI»

#### Scenario: Системные точки контакта показывают название продукта
- **Given** приложение запущено
- **When** пользователь открывает меню трея или системный дескриптор приложения
- **Then** название продукта — «Echo AI»

#### Scenario: Тексты интерфейса не содержат старого названия
- **Given** пользователь проходит по основным экранам и диалогам
- **When** отображаются тексты, описания настроек и сообщения об ошибках
- **Then** старое название продукта не встречается

### Requirement: Версия 1.0.0

Продукт MUST сообщать версию 1.0.0 согласованно во всех источниках.

#### Scenario: Версия согласована
- **Given** приложение собрано
- **When** версия запрашивается из метаданных пакета, конфигурации приложения и интерфейса
- **Then** все источники сообщают 1.0.0

### Requirement: Сохранение идентификаторов и данных

Ребрендинг MUST NOT изменять идентификаторы, определяющие расположение пользовательских данных, и MUST NOT менять канал обновлений.

#### Scenario: Данные пользователя сохраняются
- **Given** у пользователя есть установленная предыдущая версия с историей чатов, словарём и настройками
- **When** он обновляется до новой версии
- **Then** БД открывается по прежнему пути
- **And** история чатов, словарь ASR и настройки доступны

#### Scenario: Хранилище учётных данных сохраняется
- **Given** у пользователя сохранён ключ лицензии в защищённом хранилище
- **When** он обновляется до новой версии
- **Then** ключ доступен по прежнему пути

#### Scenario: Обновления продолжают доставляться
- **Given** установлена предыдущая версия
- **When** публикуется релиз новой версии
- **Then** обновление доставляется по прежнему каналу
- **And** подпись проверяется прежним ключом

### Requirement: Обновлённая визуальная идентичность

Приложение MUST использовать новый визуальный знак вместо прежнего.

#### Scenario: Иконка заменена
- **Given** приложение установлено
- **When** пользователь видит иконку приложения, окна и трея
- **Then** отображается новый знак продукта

#### Scenario: Форматы иконок корректны
- **Given** набор иконок для сборки
- **When** выполняется сборка для целевой платформы
- **Then** используются корректные форматы и размеры
