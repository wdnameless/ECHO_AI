## T2.4 — Сужение capability — DEFERRED
Отвергнуто после проверки исходников плагина, см. `design.md`: `tauri-plugin-http` 2.5.2
пересобирает scope из статического ACL на каждом вызове и не имеет `scope_mut()`,
поэтому runtime-allowlist для подтверждённого хоста невозможен без форка, а сужение
ACL сломало бы кастомных провайдеров до показа диалога (нарушение R07).
Защита реализована на уровне приложения (шлюз `host-trust-gate.ts`).
