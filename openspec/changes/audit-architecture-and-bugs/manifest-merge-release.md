# Manifest: приземление и выпуск

## Запрос пользователя (дословно)
> Делай все по порядку

Контекст выбора (дословно, из моего предыдущего сообщения, на которое это ответ):
> **3. Открыть PR** и провести проверки как положено… **2. Сначала выкатить как есть
> по тегу**… **1. Слить в `master`**
> Мой выбор — **3, с 2 как быстрым шагом**… Скажи варианту номер

Ответ пользователя «Делай все по порядку» принят как: 3 → 2 → 1.

## R## — что требовалось

- R01 | «Делай все по порядку» | Выполнить три шага в объявленном порядке: сначала
  проверки через PR, затем выпуск по тегу, затем слияние в `master`.
- R02 | «провести проверки как положено» | Прогнать слепую приёмку (`@oracle`) на
  весь диапазон `master..HEAD`, а не на отдельные правки.
- R03 | «Сначала выкатить как есть по тегу» | Выпустить релиз так, чтобы при
  неудачной сборке `master` остался чистым.
- R04 | «Слить в `master`» | Слить только после зелёных проверок; рабочее дерево
  чистое, ничего не забыто.
- R05 | «Делай все по порядку» | Ничего не пропустить из списка ранее объявленного:
  проверки, тег, слияние — все три.

Приземление диапазона `master..HEAD` (30 коммитов на момент начала, 31 после тега)
и выпуск 1.2.27. Правки кода внутри диапазона — в предыдущих манифестах.
