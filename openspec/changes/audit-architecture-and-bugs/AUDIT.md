### 1. Выбор STT-провайдера уничтожается при каждом запуске
`src/contexts/app.context.tsx:538-554`

Из storage читается сохранённый провайдер, и **сразу перезаписывается** дефолтом:

```ts
if (savedSelectedStt) {
  try { setSelectedSttProvider(JSON.parse(savedSelectedStt)); } catch {…}
  // else отсутствует — выполняется всегда
  const defaultStt = { provider: "handy-local-whisper", variables: {} };
  setSelectedSttProvider(defaultStt);
  safeLocalStorage.setItem(STORAGE_KEYS.SELECTED_STT_PROVIDER, JSON.stringify(defaultStt));
}
```

**Влияние:** любой выбор Groq/OpenAI STT затирается на старте. `catch` тоже глотает
ошибку парсинга без `else`. Ветка `if` вообще бессмысленна — обе ветви ставят дефолт.
**Триггер:** выбрать в настройках любой STT кроме локального → перезапустить → выбор исчез.

### 2. Гейт доверия (S2) обходится — ключи уходят мимо него
`src/lib/web-search.ts:201,237,272` · `src/lib/fast-translator.ts:130,200` · `src/pages/dev/components/ai-configs/Providers.tsx`

`resolveOutboundHeaders` вызывается **только** из трёх модулей (`ai-response`, `models`, `stt`).
Все остальные идут в сеть напрямую через плагин:

```ts
res = await tauriFetch(url, { headers });        // Brave: X-Subscription-Token
res = await tauriFetch(url, { method, headers, body });  // Exa: x-api-key
body: JSON.stringify({ ...JSON.parse(body), api_key: apiKey })  // Tavily: ключ в ТЕЛЕ
```

**Влияние:** `capabilities` разрешают `http://**` и `https://**` — значит гейт
единственный контроль исходящих. Он не применяется ни к веб-поиску, ни к переводчику.
`maxRedirections` тоже не передан (у гейта он `0`, здесь — дефолт плагина), то есть
редирект уводит запрос с ключом на другой хост. Tavily кладёт ключ в **тело** —
`without-secrets` вырезает только заголовки, так что даже при подключении гейта ключ бы ушёл.
**Триггер:** подставить в curl-шаблон хоста редирект на чужой домен → ключ уедет.

## Архитектура

### A1. Гейт доверия — «глубокий модуль», который обошли стороной
`host-trust-gate.ts` спроектирован правильно: fail-closed, отдельный обработчик, тесты.
Но **6 модулей** выходят в сеть, гейт вызывают **3**. Модуль не защищает границу,
потому что граница не одна: вместо перехвата на уровне транспорта каждый вызов
обязан вспомнить про гейт. Правильное место — один `gatedFetch`, через который
проходит **весь** исходящий трафик; тогда забыть невозможно по построению.
Это ровно тот случай, когда «удалить обёртку и посмотреть, где всплывёт сложность»
показывает: сложность уже размазана по вызовам.

### A2. `app.context.tsx` — 1122 строки, 16 `useState`, 11 `useEffect`, 42 поля
Контекст без селекторов: любое изменение (stealth-режим, курсор, устройство ввода)
пересоздаёт value-объект и перерисовывает **все** ~39 потребителей, включая
`SubtitleFeed` и `useSystemAudio`. `useMemo` там есть, но он не спасает: мемоизация
по 42 полям всё равно новая при любом изменении. Лечится разделением на несколько
контекстов по частоте изменений (настройки / аудио / провайдеры).

### A3. `SubtitleFeed.tsx` — 1034 строки в одном компоненте, 19 `useState`, 9 `useEffect`
Держит: очередь перевода с backoff, инлайн-правки слов, паузу ленты, дедупликацию
трёх источников (`messages` × `liveSegments` × AI-ответ), авто-скролл, self-evolution,
подписку на метрики и рендер строк. Показательно, что **оба** вчерашних дефекта перевода
родились именно здесь: состояние очереди живёт в `ref` + `useState`-тик, и связь между
ними не выражена типами. Очередь перевода просится в отдельный хук с явным состоянием.

### A4. Состояние дублируется в трёх местах
`theirLastTranscription` (состояние) + `liveSegments` (лента) + `rolledTextRef` (аккумулятор
WS) описывают одну и ту же речь. `useSystemAudio.ts:525` выбирает «свежайшее» из четырёх
источников вручную — это признак отсутствия единственного владельца. Отсюда же дефект №14.

### A5. Два канала ASR разошлись в реализации
`useMicWsStreaming` и `useThemWsStreaming` — почти копии (~370 строк каждый), но
исправления применяются по одному: у `them` ref присваивается при создании и есть
комментарий об этом, у `me` — нет (№3). Общий `asr-gate.ts` вынесен правильно, а сами
сокеты — нет. Один параметризованный хук снял бы целый класс расхождений.

### A6. Версия в четырёх файлах вручную
`package.json`, `Cargo.toml`, `Cargo.lock`, `tauri.conf.json` — я вчера забыл про bump, и
пользователь увидел «версия не меняется». Отсутствие единого источника версии — дефект
процесса, а не памяти. `release.yml` читает `tauri.conf.json`; остальные три надо
синхронизировать скриптом в `prebuild`.
