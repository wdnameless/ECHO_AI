# Proposal: Устранение White Screen в Dashboard и Адаптивность Главного Окна

## Проблема 1: Белый экран Dashboard при запуске
В продакшн сборке Tauri (`tauri://localhost` или `http://tauri.localhost`) путь `tauri::WebviewUrl::App("/chats".into())` пытается обратиться к виртуальному файлу `/chats` на статической файловой системе dist. При использовании `BrowserRouter` WebView2 возвращает 404/пустой ответ, не запуская `index.html`.
Кроме того, ошибки рендеринга на корневом уровне в окне `dashboard` не перехватываются `ErrorBoundary`.

## Проблема 2: Обрезка плейсхолдера и теснота бара ("Ask me anyl")
Фиксированная ширина главного окна 600px в `tauri.conf.json` приводит к нехватке ширины при стандартном масштабировании Windows (125%/150%), из-за чего строка поиска сжимается до нечитаемого состояния, а плейсхолдер обрезается.

## Решение
1. **Hash-роутинг и fallback для окон Tauri**:
   - Перевести `AppRoutes` в `src/routes/index.tsx` на `HashRouter`. Это гарантирует корректную загрузку корневого `index.html` во всех окнах с хэш-путями (`/#/chats`, `/#/dashboard`).
   - В `src-tauri/src/window.rs` использовать URL `"index.html#/chats"` или `tauri::WebviewUrl::App("index.html".into())` с навигацией по хэшу.
   - Обернуть корневой роутер в `src/main.tsx` в `ErrorBoundary` с выводом ошибки в случае сбоя.
2. **Адаптивность плавающего бара**:
   - Увеличить базовую ширину главного окна в `tauri.conf.json` с 600 до 680px.
   - Задать строке ввода `min-w-[140px] flex-1` и убрать принудительные жесткие рамки.
   - Добавить защитные стили для кнопок панели (`shrink-0`).
