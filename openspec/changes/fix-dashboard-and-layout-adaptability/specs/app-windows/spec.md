## ADDED Requirements

### Requirement: Окна приложения открывают корректный маршрут

В продакшн-сборке каждое окно Tauri (главное и `dashboard`) MUST загружать
корневой `index.html` и переходить на нужный маршрут, не полагаясь на
существование пути в статической файловой системе.

#### Scenario: Dashboard открывается без белого экрана
- **Given** приложение собрано в релизном режиме
- **When** пользователь открывает окно Dashboard
- **Then** окно показывает интерфейс, а не пустую страницу
- **And** активен маршрут `/chats`

#### Scenario: Навигация по страницам не перезагружает окно
- **Given** окно Dashboard открыто
- **When** пользователь переходит между разделами (Chats, Settings, Shortcuts)
- **Then** содержимое меняется без обращения к несуществующим путям

### Requirement: Ошибка рендеринга не оставляет пустое окно

Ошибка уровня рендера в любом окне MUST приводить к видимому сообщению с
возможностью перезапуска, а не к белому экрану.

#### Scenario: Падение компонента показывает экран ошибки
- **Given** в дереве компонентов произошло исключение
- **When** окно отрисовывается
- **Then** пользователь видит экран с сообщением и кнопкой перезагрузки

### Requirement: Плавающая панель сохраняет читаемость при масштабировании

Главное окно MUST сохранять читаемую строку ввода при типовом масштабировании
Windows (100–150%) и не обрезать плейсхолдер.

#### Scenario: Плейсхолдер не обрезается
- **Given** системное масштабирование 125% или 150%
- **When** открыто главное окно
- **Then** строка ввода занимает доступную ширину и плейсхолдер читается целиком
- **And** кнопки панели не сжимаются и не наезжают на поле ввода

### Requirement: Перемещение окна доступно вне зависимости от тарифа

Перетаскивание главного окна и перемещение его клавиатурой MUST работать при
неактивной лицензии.

#### Scenario: Окно перемещается на бесплатном тарифе
- **Given** лицензия не активна
- **When** пользователь использует перетаскивание и хоткеи перемещения
- **Then** окно перемещается
