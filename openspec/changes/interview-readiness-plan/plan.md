# План: до «проходить любое собесо» (RU + EN, скорость + точность)

Источник: гэп-анализ по коду 2026-10-01 (весь пайплайн прочитан, цифры из
`metrics.ts`, замеры в комментах движка). По убыванию: дешевле и больше
эффекта — выше.

## P0 — прогрев перед собесом (скорость, 1 день)
- **Что:** `warmUp()` на старте режима Встреча: поднять движок + выбранную
  модель, прогреть соединение провайдера (HEAD/пустой запрос), собрать
  RAG-промпт в кэш, прогреть первый batch-проход.
- **Зачем:** первый вопрос собеса сейчас платит холодный старт целиком;
  `warm_llm_connection` греет только при вопросе, а не заранее.
- **Где:** `useSystemAudioCapture.startCapture` (вход), `useQuestionPipeline`
  (warm существует — вынести раньше), `ai-response` (RAG-кэш).
- **Приёмка:** TTFT первого ответа ≤ второго (не «первый медленнее»);
  `lastFirstTextMs` на первой реплике < 800мс на нормальном железе.

## P1 — дамп метрик по кнопке (диагностика, 1 день)
- **Что:** кнопка в футере «Дамп сессии»: модель/пресет/язык + partial /
  first-text / TTFT / rec / lost за сессию в файл или буфер.
- **Зачем:** «у меня медленно» сейчас ощущение; дамп делает цифрами и
  позволяет чинить точечно.
- **Где:** `metrics.ts` уже всё держит; кнопка в `SubtitleFeed` футере рядом с ⟲.
- **Приёмка:** клик → файл/буфер с JSON всех метрик + контекст, одним нажатием.

## P2 — языковой бейдж + предупреждение о рассинхроне (bilingual, 1 день)
- **Что:** `detectLanguage` на каждой финальной реплике; в статусе «язык: RU/EN»;
  при рассинхроне с активной моделью (говорят EN, активна RU) — бейдж
  «переключить?» рядом с сегментом, не авто.
- **Зачем:** на смешанном созвоне говорящий на EN попадает в RU-модель → мусор.
- **Где:** `language-detect.ts` (есть), `SubtitleFeed` (место есть), свитч.
- **Приёмка:** реплика на английском при активной RU показывает бейдж;
  клик по бейджу = тот же `switchTo("en")`.

## P3 — скриншот → OCR → кодовый ответ (код, самый большой выигрыш, 2-3 дня)
- **Что:** скриншот кода на экране интервьюера → текст → кодовый ответ.
  Кодовый путь сейчас только текстовый (шаблоны + модель).
- **Зачем:** лайв-кодинг 80% собеса; сложные задачи (дебаг на экране,
  system design) без скриншота не дотянуть.
- **Где:** `capture_to_base64` уже есть; `code-answer` принимает скриншот как
  контекст к `processWithAI` (imagesBase64 уже поддерживается).
- **Приёмка:** скриншот блока кода + «почини» → модель отвечает исправленным
  фрагментом с табами.

## P4 — фолбэк-цепочка AI-провайдеров (надёжность, 1-2 дня)
- **Что:** при таймауте/429/сетевой ошибке активного провайдера — следующий
  из списка, без ручного переключения.
- **Зачем:** один провайдер = один источник сбоев на собесе; ответ теряется.
- **Где:** `stt-fallback.ts` — образец; `ai-response.function.ts` — точка.
- **Приёмка:** 429 от первого → второй отвечает без дырки в стриме.

## P5 — GigaAM как RU-движок (точность RU, 2-4 дня, отдельный слайс)
- **Что:** настоящий GigaAM (SOTA русского, win 70:30 vs Whisper-large-v3)
  через gguf-конвертацию или ONNX-обёртку; в каталоге сейчас только старые
  ветки (WER 8.07) — не та линейка.
- **Зачем:** TDTv3 (WER 1.94) — потолок каталога, не потолок русского.
- **Где:** `src-tauri/src/models.rs` + движок; отдельный слайс с тестами.
- **Приёмка:** RU-replика короче и точнее на реальных фразах, WER лучше 1.94.

## OUT (осознанно)

- Два движка одновременно (двойной RAM).
- Облачный STT как основа (приватность + сеть); как фолбэк — отдельный слайс.
