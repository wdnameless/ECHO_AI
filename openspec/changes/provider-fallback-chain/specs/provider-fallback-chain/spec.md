# Spec: provider-fallback-chain

## MUST
- Любая ошибка провайдера (сеть, HTTP, парс, trust, STALL, пусто) ведёт дальше.
- Аборт пользователем — не фолбэк.
- Порядок: выбранный первым, без дублей.
- Маркер переключения виден; склейки обрывков нет.
- Исчерпание называет всех пробованных и последнюю причину.

## MUST NOT
- Ретрай того же провайдера вместо следующего (блип уже покрыт внутри).
- Тихий дроп склейки; общая «все недоступны» без имён.
