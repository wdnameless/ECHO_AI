# Manifest: P4 фолбэк-цепочка провайдеров

## R01 — любая ошибка переключает на следующий
- Quote: "Что переключает на следующий?" → "Любая ошибка провайдера"
- Change: 429, таймаут, сеть, 5xx, пустой стрим — всё ведёт на следующего; отдельный ретрай того же провайдера не делаем (второй шанс тому же ключу не поможет)
- Evidence: тест: первый бросает 429 → вызывается второй; первый бросает сеть → вызывается второй

## R02 — порядок: выбранный, затем остальные по списку
- Quote: "Порядок обхода?" → "Выбранный, затем остальные по списку"
- Change: цепочка = [selected, ...allAiProviders минус selected]; кастомные провайдеры участвуют наравне (они в allAiProviders)
- Evidence: тест: порядок = выбранный первым, остальные следом без дублей

## R03 — «переключаю» + ответ заново
- Quote: "Частичный стрим при переключении?" → "Показать «переключаю» и начать заново"
- Change: при переключении в стрим вшивается строка `(переключаю на <имя>…)` и fullResponse сбрасывается — кандидат видит разрыв, а не склейку двух half-ответов
- Evidence: в ответе есть маркер переключения; склейки обрывков нет

## R04 — исчерпание: ошибка последнего + список пробованных
- Quote: "Все упали: что видит кандидат?" → "Ошибка последнего + список пробованных"
- Change: `Все провайдеры недоступны (пробовали: A, B): <последняя ошибка>` — кандидат знает, что чинить (ключ? сеть?)
- Evidence: тест: все бросают → ошибка содержит имена и последнюю причину
